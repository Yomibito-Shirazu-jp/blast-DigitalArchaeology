## 保全方針

- 歴史的Blastコード、コミットSHA、検証用スクリプトの原本はそのまま保存。
- 上流コードと研究成果を混在させない。既存実装を改変して成功を演出しない。
- 秘密鍵・実行可能な未修正の窃取手順・未公開脆弱性詳細は一般公開しない。
- 実験用のアドレスと資産管理の実在する秘密情報を混同しない。
