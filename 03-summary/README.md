# 03 — サマリー｜研究全体の見取り図

**Digital Archaeology / Dig, Don't Hack**

目的：歴史的なコントラクトの来歴を復元し、資産の**所在・数量・権利者・回収条件**を、誰でも検証可能な証拠で示すこと。回収そのものは正当な権利者に委ねます。
