## Mandatory case map

Every case has a human-readable **Recovery Map** and machine-readable JSON, both with accurate evidence status and public-safety clearance. Use [the template](../methodology/RECOVERY_MAP_TEMPLATE.md) and [case policy](../methodology/RECOVERY_MAP_POLICY.md). Legacy cases receive retrospective maps only after evidence inspection; do not invent past validation.

Do not list unverified balances as recovered funds. Record each case's historical block and corresponding deployment context, ownership/authorization constraints and latest reviewed commit.
