## Archaeology status

A successful `eth_call` is a read-only execution result. A local fork can demonstrate a **conditional, simulated** transfer with the stated caller context. Neither implies a production-chain transfer, control of a real private key, or permission to claim somebody else's funds.

Research claims must be backed by precise immutable versions and independently reproducible artifacts.
